# Knowledge

Owned by the `knowledge-steward` agent (`.claude/agents/knowledge-steward.md`).

- `PROPOSALS/` holds schema, process and policy changes that need a human decision. Each proposal states the exact change, its rollback, and its evidence. Nothing in this folder is applied automatically.
- SOPs live in `docs/sop/`. Graph data lives in `knowledge/graph/`. Training and evaluation corpora live in `knowledge/training/`.
