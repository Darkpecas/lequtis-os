# LeQutis Initial Architecture

LeQutis is a persistent agentic partner.

Permanent concepts:
- identity
- relationship continuity
- memory
- knowledge
- skills
- experience
- agenda
- evidence
- evolutionary history

Replaceable concepts:
- LLM
- coding agent
- tool provider
- orchestration implementation
- storage implementation
- individual skills

Evolution loop:

experience
-> evaluation
-> learning
-> knowledge/skill update
-> limitation detection
-> improvement proposal
-> sandbox experiment
-> benchmark
-> migration
-> monitoring
-> rollback

The current architecture is deliberately evolutionary.
